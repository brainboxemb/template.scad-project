# template.scad-project plan

## Purpose

This repository is the qualified reference consumer for the current shared SCAD
project architecture. It demonstrates how a normal project consumes released
shared tooling and reusable libraries without becoming the owner of those
mechanisms.

## Current position

Migration 011 updates the template **last**, after the same baseline has been
qualified in maintained libraries, the HUB75 display-frame project and the
retained HUB75 component lab.

The template intentionally exercises `scad.docs`, `scad.build` and
`scad.verify`; OpenSCAD + PythonSCAD; SCons; one reusable external library;
generated design documentation; Build/Verification publication; and coordinated
release composition.

## Working method

1. inspect current config, open issues/PRs, live CI and publication provenance;
2. determine whether proposed behavior belongs in a shared owner first;
3. qualify owner changes before updating the reference consumer;
4. keep the template representative but understandable;
5. avoid copying volatile shared-tool implementation details into template docs;
6. preserve a small concrete model and real verification cases.
