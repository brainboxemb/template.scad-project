# template.scad-project user manual

## What this repository is for

Use this repository when you want to see one concrete current-generation SCAD
consumer rather than reading shared tooling in isolation. It is deliberately
broader than the smallest possible project.

## Clone and bootstrap

```powershell
.\bootstrap.ps1
```

or:

```bash
./bootstrap.sh
```

Then invoke the pinned local tool, for example:

```powershell
.\tools\tool.scad-project\scad-project.ps1 build
.\tools\tool.scad-project\scad-project.ps1 verify
```

## Where to look

- `dsg/openscad/main.scad` — interactive OpenSCAD model;
- `prod/bld` — latest generated Build publication;
- `prod/vrf` — latest generated Verification publication;
- `prod/bld/design/README.md` — generated visual design documentation;
- [30-00-specification.md](30-00-specification.md) — why each representative path is present.

A real project should keep only the engines, capabilities and dependencies it
actually needs.
