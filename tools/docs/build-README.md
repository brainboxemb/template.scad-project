# Generated build output

This branch contains generated output for the current successful project build.
It is replaced automatically and is not the source-of-truth branch.

## Navigation

- [Design documentation](design/README.md)
- [PNG renders](png/)
- [STL exports](stl/)

## Branch roles

```text
main
    source code
    source design documentation
    project configuration

build
    generated design documentation
    PNG renders
    STL exports
```

Do not edit files on this branch manually. Changes will be replaced by the next
successful build publication.
